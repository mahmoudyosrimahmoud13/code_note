// run code

    
Run it right in the note.

    
Python, Bash, Node.js, TypeScript and Dart run inside your notes, in a sandbox that keeps them away from the rest of your files. Python, Node.js and Dart run on Windows, Linux and macOS; Bash runs on Android too.


    

      

        
Python that works like Jupyter

        
The Python blocks of a note share one kernel, so a df made in one block is there in the next. Every block gets a ▶ button, and Run note runs them all in order.

        
    
          
  • Rich output from any library: pandas tables, matplotlib and seaborn plots, images, HTML, the same way Jupyter shows them
    • 
          
  • In [n] counters, Interrupt that keeps your variables, and Restart kernel
    • 
          
  • %pip install and !commands in any block, and input() works too
    • 
          
  • Save the output under the block: text, tables and plots become blocks of the note
    • 
          
  • Open Jupyter notebooks (.ipynb) as notes: cells become blocks, and saved outputs and plots come alongcoming in 1.8.1
    • 
          
  • Jupyter shortcuts: Shift Enter runs and moves on, Esc then A / B / D D / M like in Jupytercoming in 1.8.1
    •

Everything runs in a sandbox

        
Each folder of notes gets its own sandbox folder. Scripts start there, and their home, temp and cache folders all point there. Anything they download stays there until you choose Save a copy.

        
    
          
  • Android and macOS: the system keeps CodeNote in its own space
    • 
          
  • Linux: bubblewrap hides your home folder and drives from scripts
    • 
          
  • Windows: scripts get their own folder, and running code needs your OK first
    • 
          
  • On Windows and Linux, runtimes download from their official sources into the sandbox, never into your system (macOS uses the ones you have). Update packages, or clear everything, from Settings
    • 
          
  • Expose sandbox, off by default: when you trust the code, let it reach your own files (Linux, Windows)coming in 1.8.1
    •

⇄Backend + frontend
Notes in one folder share a sandbox. Run a FastAPI server in one note and the web page in another can call it.

      
↧Run a whole folder
Set the order, skip steps, and mark the main block that runs last and keeps running. Runs keep going when you leave the note.

      
▦Mini apps
An HTML note is a small app that can save its data. Try the Snake game in the demos.

      
◎Demos to start from
A YouTube downloader with every option, a FastAPI backend, a pandas cookbook and a PyTorch model.

      
≡Live progress
Package downloads show a progress bar, and a ring on ▶ shows what's still running.

      
⧉Share as .codenote
Send a note or a whole folder as one file: blocks, images, run order and saved app data.

      
$Bash everywhere
Bash and shell blocks run on Linux, macOS and Android. On Windows CodeNote downloads BusyBox for you.

      
◫Open .ipynb
Open a notebook from Jupyter, Colab or Kaggle and it becomes a note you can run. coming in 1.8.1

      
↵Double-click to open
Double-click a .codenote file and it opens in CodeNote, even when CodeNote is already open. coming in 1.8.1

      
⌗Sandbox folder
Open the sandbox in your file manager from Settings, to see what your scripts made. coming in 1.8.1

      
>_Terminal
A shell that starts in the note's sandbox folder, one tap away from any run.

      
◇Dart and TypeScript
The Dart SDK and TypeScript run straight from a block. On Windows and Linux CodeNote downloads them once.

      First time opening it?
      

        
Windows
SmartScreen may say "Windows protected your PC". Click More info, then Run anyway. This happens because the app isn't code-signed yet.

        
Mac
The app isn't notarized yet, so the first time, right-click CodeNote and choose Open, then Open again.

        
Linux
In a terminal: sudo apt install ./CodeNote-*-linux-amd64.deb. For the .tar.gz, extract it and run ./code_note.
